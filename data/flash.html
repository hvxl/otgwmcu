Flash PIC

The OTGW can be used to flash a blank PIC16F1847. To be able to do this, 2 wires must be added to the circuit:
  1. From Wemos pin D6 to PIC pin 12
  2. From Wemos pin D7 to PIC pin 13
Nodo shop OTGW hardware versions 1.12 and later have 2 sets of jumper pads marked "LVP" that facilitate making these connections.

Monitor the debug port (port 45256) for notifications about the result.

Note: If the PIC is not blank but has low voltage programming (LVP) enabled, this will erase the old program.
